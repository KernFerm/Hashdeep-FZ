# Hashdeep FZ v1.0.4

Hashdeep FZ hashes actual microSD file bytes with native MD5, SHA-1, and SHA-256 support, creates and audits manifests, and can control genuine Hashdeep on a Raspberry Pi or other Linux computer through UART.

This maintenance release refreshes application/companion version metadata and is clean-built and validated for Flipper target f7/API 87.1.

Download `hashdeep_fz.fap` and copy it to `/ext/apps/Tools/` on the Flipper.
